# 本地运行步骤（Windows / macOS 通用）

> 目标：5 分钟内跑起来。全部在本机跑，数据存在 `data/app.db`，不联网、不花钱。

---

## 0. 环境要求

| 项目 | 要求 |
|---|---|
| Python | 3.11 或更高（3.9 也能跑，推荐 3.11） |
| 浏览器 | Chrome / Edge 任意新版 |
| 网络 | 仅安装依赖时需要 |

检查 Python：
```bash
python --version      # Windows
python3 --version     # macOS / Linux
```

---

## 1. 安装依赖

```bash
cd class_eval

# 建虚拟环境（推荐，避免污染系统 Python）
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

# 安装依赖（国内加镜像会快很多）
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

> 只跑本地模式时，`supabase` / `psycopg` 装不装都能跑（代码里是延迟导入）。
> 但如果打算后面上云，建议一次装完。

---

## 2. 准备配置文件

```bash
# Windows
copy .env.example .env
# macOS / Linux
cp .env.example .env
```

打开 `.env`，本地开发只需要确认这两行：
```ini
APP_MODE=local
DEFAULT_ADMIN_PASSWORD=admin123     # 首次登录用的管理员密码
```

其余云端的 `SUPABASE_*`、`DATABASE_URL` 全部留空即可。

---

## 3. 环境自检（强烈建议先跑这一步）

```bash
python tools/check_env.py
```

它会把 Python 版本、依赖、数据库建表、目录权限、Excel 导出能力全过一遍。
看到 **「环境检查通过」** 就说明没问题；本地模式第一次跑会自动建表。

---

## 4. 启动

```bash
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。
若没自动打开，手动访问该地址；想换端口：

```bash
streamlit run app.py --server.port 8600
```

想让同一局域网内的手机/平板访问（同一 Wi-Fi 下的家长测试）：
```bash
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```
然后用电脑的局域网 IP 访问，如 `http://192.168.1.23:8501`。

## 5. 首次使用流程（5 分钟走一遍）

| 步骤 | 位置 | 操作 |
|---|---|---|
| ① 登录 | 首页「老师登录」 | 账号 `admin` / 密码 `admin123` |
| ② 改密码 | 设置与导出 → 账号安全 | **必做**，默认密码只用于首次登录 |
| ③ 建班 | 班级管理 → 新建班级 | 填「八年级(3)班」，勾选"创建默认标签和小组" |
| ④ 录学生 | 班级管理 → 学生名单 → 批量导入 | 粘贴 `01,张三,男,第一组` 每行一人 |
| ⑤ 打分 | 积分评价 | 先点标签，再点学生头像下方的分按钮 |
| ⑥ 看榜 | 积分榜单 / 纯净投屏 | 投屏页隐藏侧边栏，适合教室大屏 |
| ⑦ 家长 | 首页「家长查看」 | 用学生的学号 + 家长查看码登录（查看码在学生与标签页） |

> 打开多个浏览器窗口 / 无痕窗口，可以同时扮演班主任、科任、家长三种角色测试权限。

## 7. 常见问题

**Q1：`streamlit` 命令找不到？**
用 `python -m streamlit run app.py` 代替。

**Q2：端口被占用？**
`--server.port 8600` 换一个；或关掉占用的进程。

**Q3：改完代码页面没变化？**
Streamlit 通常会自动热重载；若改了 `config.py`/`.env`，按 `R` 或刷新页面。
改了 `core/*.py` 后建议直接 `Ctrl+C` 重启，避免模块缓存。

**Q4：数据想清空重来？**
停掉服务，删除 `data/app.db`，重启后会自动重建（管理员账号也会重置为 admin/admin123）。
⚠️ 这会清空所有班级与记录，操作前先备份。

**Q5：想换数据库位置？**
在 `.env` 里加 `SQLITE_PATH=D:/你的路径/app.db`。

**Q6：中文乱码 / 表格列名不对？**
导出的 CSV 用 `utf-8-sig` 编码，Excel 直接双击能正常显示；
Excel 台账（.xlsx）没有编码问题。
