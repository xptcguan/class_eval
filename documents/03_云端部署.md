# 云端部署（Supabase + Streamlit Community Cloud）

> 免费额度：Supabase 免费版（500MB 数据库 + 1GB 存储）；Streamlit Community Cloud 免费（1 个 app 常驻，长期无访问会休眠，有访问自动唤醒）。  
> 关键点：**容器会休眠重启，所以 SQLite 一定丢数据 → 必须切 Supabase。**

---

## 一、Supabase 新建项目（约 8 分钟）

### 1. 注册与建项目

1. 打开 <https://supabase.com> → 用 GitHub 或邮箱注册登录
2. **New project**
   - Organization：默认即可
   - Name：`class-eval`
   - Database Password：**点 Generate 生成强密码，立刻复制保存**（后面 DATABASE_URL 要用）
   - Region：选 `Southeast Asia (Singapore)`（离国内近，延迟低）
   - Plan：Free
3. 点 Create new project，等 1~2 分钟初始化完成

### 2. 执行建表脚本

1. 左侧菜单 **SQL Editor** → **New query**
2. 打开本项目的 `sql/schema_supabase.sql`，**全文复制**粘贴进去
3. 点 **Run**（或 Ctrl+Enter）
4. 看到 `Success. No rows returned` 即建表完成
5. 左侧 **Table Editor** 里应能看到 9 张表：`teachers`、`classes`、`teacher_classes`、`students`、`eval_tags`、`groups`、`score_logs`、`audit_logs`、`class_settings`

### 3. 创建 Storage 桶（图片存储）

1. 左侧 **Storage** → **New bucket**
2. Bucket name：`class-eval`
3. **Public bucket 勾选 ✅**（这样图片 URL 可以直接给家长看）
4. File size limit：`5 MB`
   1. Allowed MIME types：`image/png`, `image/jpeg`, `image/webp`
5. Create

> 也可以不勾 Public，但那样图片需要签名 URL（会过期），本项目按 Public 设计。

### 4. 取三个密钥

| 名称                   | 在哪拿                                                                              | 用途                                    |
| -------------------- | -------------------------------------------------------------------------------- | ------------------------------------- |
| **Project URL**      | Project Settings → Data API → Project URL<br />形如 `https://abcdefgh.supabase.co` | 填 `SUPABASE_URL`                      |
| **service_role key** | Project Settings → API Keys → `service_role`（点 Reveal）                           | 填 `SUPABASE_SERVICE_KEY`（**绝不能给浏览器**） |
| **DATABASE_URL**     | 右上 **Connect** → **Session pooler** → 复制那条 URI                                   | 填 `DATABASE_URL`（psycopg 直连）          |

`DATABASE_URL` 形如：

```
postgresql://postgres.abcdefgh:你的数据库密码@aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres
```

⚠️ **两个坑**：

- 一定选 **Session pooler**，不要用 `Direct connection`（IPv6，Streamlit Cloud 连不上）
- 数据库密码如果含 `@ : / ? #` 等字符，要做 URL 编码（如 `@` → `%40`）；最省事的办法是建项目时用 Generate 的字母数字密码

### 5. （可选）关闭邮箱验证干扰

如果只想用应用自己的账号体系，不用 Supabase Auth：  
**Authentication → Providers → Email** 可以关掉。本项目完全不使用 Supabase Auth，账号密码存在 `teachers` 表里（PBKDF2 哈希），这一步可跳过。

## 二、代码推送到 GitHub（约 3 分钟）

Streamlit Community Cloud 只从 GitHub 拉代码。

```bash
cd class_eval
git init
git add .
git commit -m "feat: 班级评价管理系统 v1.0"
git branch -M main
git remote add origin https://github.com/你的用户名/class-eval.git
git push -u origin main
```

⚠️ **推送前确认**：

- `.env` 没有被提交（`.gitignore` 已排除）
- `data/app.db`、`data/uploads/` 没被提交
- `.streamlit/secrets.toml` 没被提交

检查命令：

```bash
git status --short           # 不应出现 .env / app.db
git ls-files | grep -E "\.env$|\.db$|secrets\.toml"   # 应无输出
```

## 三、Streamlit Community Cloud 部署（约 5 分钟）

### 1. 创建 App

1. 打开 <https://share.streamlit.io> → **Sign in with GitHub** → 授权
2. 右上 **Create app** → **Deploy a public app from GitHub**
3. 填写：
   - Repository：`你的用户名/class-eval`
   - Branch：`main`
   - **Main file path**：`app.py`
   - App URL：自定义子域名，如 `class-eval-demo`
4. 先别点 Deploy —— 右下角 **Advanced settings** 填 Secrets（下一步）

### 2. 填入 Secrets

在 **Advanced settings → Secrets** 里粘贴（TOML 格式，缩进敏感）：

```toml
APP_MODE = "cloud"

SUPABASE_URL = "https://abcdefgh.supabase.co"
SUPABASE_SERVICE_KEY = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...."
DATABASE_URL = "postgresql://postgres.abcdefgh:你的密码@aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres"
SUPABASE_BUCKET = "class-eval"

ALLOW_TEACHER_SIGNUP = "true"
DEFAULT_ADMIN_USER = "admin"
DEFAULT_ADMIN_PASSWORD = "请换成一个强密码"
SHOW_RANK_DEFAULT = "true"

# 家长登录令牌签名密钥：随便一长串随机字符，不要外泄
APP_SECRET_KEY = "随便一长串随机字符-至少32位-abc123xyz"

# 教室投屏口令
PLAY_CODE = "8888"
```

> 本项目配置读取顺序是：**系统环境变量 > .env > Streamlit Secrets**，  
> 所以云端只要 Secrets 里配好，代码不需要任何改动。

### 3. Deploy

点 **Deploy!**，等 2~4 分钟构建。成功后得到地址：

```
https://class-eval-demo.streamlit.app
```

### 4. 首次登录与验证

1. 打开上面的地址 → 用 `admin` + 你在 Secrets 里设的 `DEFAULT_ADMIN_PASSWORD` 登录
2. **立即改密码**：设置与导出 → 账号安全
3. 建一个测试班 → 录 3 个学生 → 打一次分 → 传一张图片
4. 到 Supabase → Table Editor 检查：`students` 有数据、`score_logs` 有记录
5. 到 Supabase → Storage → `class-eval` → `score/日期/` 里应能看到刚上传的图
6. **休眠验证**（最重要）：
   - 关闭浏览器，等待 app 休眠（约 10~20 分钟无访问，或到 Streamlit 后台点 **Sleep**）
   - 重新访问 → 数据仍然在 ✅
   - 如果数据没了，说明 `APP_MODE` 或 `DATABASE_URL` 配错了，还在用本地 SQLite

### 5. 挂到自己的域名（可选）

Streamlit Cloud 免费版支持**自定义子域名**，不支持绑定自有域名。  
家长/学生访问用 `https://xxx.streamlit.app` 即可；  
若要用自有域名，需在前面加一层反向代理（如 Cloudflare Worker），超出本项目范围。

## 四、三种角色怎么用同一个链接

| 角色   | 首页选哪个 tab     | 拿到什么                  |
| ---- | ------------- | --------------------- |
| 班主任  | 👩‍🏫 老师登录    | 全部权限                  |
| 科任老师 | 👩‍🏫 老师登录    | 只能给被分配的班级打分、看榜单、看日志   |
| 学生家长 | 👨‍👩‍👦 家长查看 | 选班级 + 学号 + 查看码，只看自家孩子 |

## 五、添加科任老师（不让他们自助注册的话）

推荐流程（更可控）：

1. 关闭自助注册：Secrets 里 `ALLOW_TEACHER_SIGNUP = "false"`
2. 班主任登录 → **班级管理 → 科任老师 → 新建账号并加入** → 填账号、初始密码、学科
3. 把账号密码告诉该老师；他首次登录后会被要求改密码（`must_change_pwd=1`）

## 六、数据备份

| 内容   | 方式                                                                   |
| ---- | -------------------------------------------------------------------- |
| 数据库  | Supabase 控制台 → **Database → Backups**（免费版有每日备份，保留 7 天）；或本地 `pg_dump` |
| 图片   | Storage 桶整桶下载；或对自己的文件另存一份                                            |
| 业务台账 | 应用内「设置与导出 → 生成台账文件」，定期导出 Excel 留档（推荐每学期一次）                           |

`pg_dump` 示例（本地装了 PostgreSQL 客户端）：

```bash
pg_dump "postgresql://postgres.xxx:密码@aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres" \
  -f backup_20261122.sql
```

## 七、成本与限额（免费版）

| 资源      | 免费额度                                    | 本系统占用（40 人 × 3 班）            |
| ------- | --------------------------------------- | ---------------------------- |
| 数据库     | 500 MB                                  | 每学期约 2~5 万条记录 ≈ 15 MB        |
| Storage | 1 GB                                    | 每张图压缩后约 200KB，1 万张 ≈ 2 GB ⚠️ |
| 月活用户    | 不限                                      | 几十人                          |
| 休眠      | 无访问 7 天后休眠（Community Cloud 也有 7 天主会话限制） | 唤醒后几秒恢复                      |

> **图片是唯一可能超额的资源**。建议：只有重要扣分才拍照；定期清理旧图片（Storage 里按日期目录删除）。

## 八、云端排错速查

| 现象                                            | 原因                         | 解决                                    |
| --------------------------------------------- | -------------------------- | ------------------------------------- |
| 启动报 `DATABASE_URL 缺失`                         | Secrets 没配或拼错              | Secrets 里加 `DATABASE_URL`，注意是 TOML 格式 |
| 报 `no such table` / `relation does not exist` | 没执行 `schema_supabase.sql`  | 回 Supabase SQL Editor 执行一次            |
| 报 `password authentication failed`            | 密码含特殊字符未编码                 | 用 `%40` 等替换，或重置数据库密码为纯字母数字            |
| 报 `Network is unreachable` / 连接超时             | 用了 Direct connection（IPv6） | 改用 **Session pooler** 连接串             |
| 图片能传但显示 403                                   | 桶不是 Public                 | Storage → 桶设置 → 改 Public；或撤销后重建       |
| 重启后数据全没                                       | `APP_MODE` 还是 local        | Secrets 里改成 `"cloud"`                 |
| 改完 Secrets 没生效                                | 需要重启 app                   | Streamlit 后台 → Manage app → Reboot    |
| 页面很慢                                          | 免费容器冷启动                    | 首次访问等 10~20 秒，属正常                     |
